# Orbitra - AI Travel Planner

An AI-powered travel itinerary generator built with MERN stack.

## Live Demo
- **Frontend:** https://orbitra-itinerary.vercel.app
- **Backend:** https://orbitra-backend-75je.onrender.com

## GitHub
https://github.com/dhanadevunoori/orbitra-itinerary

## Tech Stack
- Frontend: React.js, Vite
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- AI: Groq (LLaMA 3)
- Auth: JWT

## Features
- JWT Authentication
- PDF/Image upload
- AI itinerary generation
- Trip history
- Share itineraries
- Public/Private toggle
- Drag and drop upload
